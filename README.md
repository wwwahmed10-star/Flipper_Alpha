Flipper Alpha 🐬⚡
An open-source, multi-tool hardware device inspired by the Flipper Zero, built for hardware enthusiasts and cybersecurity learners at a fraction of the cost.

🚀 About the Project
Flipper Alpha is designed to provide core multi-tool capabilities (RFID, NFC, Sub-GHz communication, infrared, and GPS) while keeping the cost under a quarter of the original Flipper Zero price. It is fully modular, allowing you to upgrade, modify, and expand its features based on your needs.

🛠️ Core Hardware Architecture
The project integrates an 11-component architecture, including:

Microcontroller: ESP32-S3-WROOM-1

RFID / NFC: PN532 Module

Sub-GHz Wireless: CC1101 & NRF24L01+ Modules

Positioning: NEO-6M GPS Module

Infrared (IR): IR Transmitter and TSOP38238 Receiver

Power & Supporting Passives: Resistors, Capacitors, and connectors.
